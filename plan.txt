1. HIPAA TECHNICAL SAFEGUARDS COMPLIANCE (45 CFR Part 164)
--------------------------------------------------------------------------------
* § 164.312(a)(1) Access Control:
  - Unique user identification and credential management.
  - Role-Based Access Control (RBAC): Admin vs Clinic Staff.
  - Multi-tenancy: Clinic A cannot view data from Clinic B.
  - Strong password policy enforced (min 10 chars, uppercase, lowercase, numbers, symbols).
  - Bcrypt password hashing (salt rounds: 12).

* § 164.312(a)(2)(iii) Automatic Logoff:
  - Enforce session timeout after 15 minutes of inactivity.
  - Visual warning countdown before auto-logout occurs.

* § 164.312(a)(2)(iv) Data Encryption at Rest:
  - Field-level encryption using AES-256-GCM for all patient identifiers (Patient Name, DOB, Subscriber ID).
  - Encryption keys stored securely in environment variables, never committed to git.

* § 164.312(b) Audit Controls & Audit Trail:
  - Tamper-evident logging of all ePHI access events:
    [TIMESTAMP] [USER_ID] [OFFICE_ID] [ACTION] [RECORD_ID] [IP_ADDRESS] [USER_AGENT]
  - Actions logged: LOGIN, LOGOUT, ANALYZE_FILE, VIEW_HISTORY_ITEM, EXPORT_EXCEL, DELETE_RECORD.
  - Audit logs are append-only; standard users cannot modify or delete audit trails.

* § 164.312(e)(1) Transmission Security:
  - Full TLS 1.3 / HTTPS enforced via Cloudflare and Nginx.
  - HSTS enabled.

2. DATABASE ARCHITECTURE (POSTGRESQL)
================================================================================

A. practices (Organizations / Clinics)
   - id: UUID (Primary Key)
   - name: VARCHAR(255)
   - subscription_tier: VARCHAR(50) DEFAULT 'pro'
   - created_at: TIMESTAMP WITH TIME ZONE DEFAULT NOW()

B. users (Clinic Accounts)
   - id: UUID (Primary Key)
   - practice_id: UUID (Foreign Key -> practices.id)
   - email: VARCHAR(255) UNIQUE NOT NULL
   - password_hash: VARCHAR(255) NOT NULL
   - full_name: VARCHAR(255) NOT NULL
   - role: VARCHAR(50) DEFAULT 'staff'  -- 'admin' or 'staff'
   - is_active: BOOLEAN DEFAULT TRUE
   - last_login_at: TIMESTAMP WITH TIME ZONE
   - created_at: TIMESTAMP WITH TIME ZONE DEFAULT NOW()

C. verifications (Persistent Insurance History)
   - id: UUID (Primary Key)
   - practice_id: UUID (Foreign Key -> practices.id)
   - user_id: UUID (Foreign Key -> users.id)
   - patient_name_enc: TEXT NOT NULL         -- AES-256-GCM encrypted
   - member_id_enc: TEXT                     -- AES-256-GCM encrypted
   - insurance_payer: VARCHAR(255)
   - network_status: VARCHAR(100)
   - full_breakdown_json: JSONB NOT NULL     -- Complete structured breakdown data
   - created_at: TIMESTAMP WITH TIME ZONE DEFAULT NOW()

D. audit_logs (Immutable HIPAA Access Logs)
   - id: UUID (Primary Key)
   - user_id: UUID (Foreign Key -> users.id)
   - action: VARCHAR(100) NOT NULL           -- 'LOGIN', 'VIEW_RECORD', etc.
   - target_id: UUID                         -- verification ID accessed
   - ip_address: VARCHAR(45)
   - user_agent: TEXT
   - metadata: JSONB
   - created_at: TIMESTAMP WITH TIME ZONE DEFAULT NOW()
