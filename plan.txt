NEXT UP: BACKGROUND HEADLESS BROWSER VERIFICATION (PLAYWRIGHT AUTOMATION)
--------------------------------------------------------------------------------
* Objective: Staff enters Member ID + DOB + Payer -> System opens a background
  headless browser, logs into the provider portal, retrieves live benefits,
  and renders the full breakdown table automatically.

1. Unified Auto-Verify Input Panel in Frontend:
   - Toggle switch on main screen:
     [⚡ Run Background Auto-Verify]  vs  [📄 Manual Document Upload]
   - Input Fields:
     * Insurance Portal Dropdown: [DD CA | DD FEP | Cigna | MetLife | Guardian]
     * Subscriber / Member ID: [____________________]
     * Patient DOB: [MM/DD/YYYY]
     * Patient Name: [Last, First]
   - Button: [⚡ Run Auto-Verify & Generate Breakdown]
   - Live Progress Status Indicator:
     "Launching background runner..." -> "Authenticating into portal..." ->
     "Fetching patient benefits..." -> "AI Clinical Audit in progress..." -> "Done!"

2. Backend Playwright Automation Runner:
   - Headless browser runner hosted on VPS (`automation/payers/`).
   - Loads encrypted clinic credentials for selected portal from PostgreSQL vault.
   - Navigates to portal login URL and authenticates.
   - Enters Patient Subscriber ID and DOB into portal search form.
   - Captures benefits summary (PDF download or HTML DOM snapshot).
   - Hands document buffer directly into Gemini AI RCM audit pipeline.

3. Human-in-the-Loop 2FA / OTP Relay Modal:
   - If portal prompts 2FA SMS or email code on login:
     * Runner pauses and triggers live OTP prompt in DentVerify frontend:
       "2FA Code Required: Enter code sent to clinic [phone/email]: [ _____ ] [Verify]"
     * Staff enters code -> runner resumes session and completes patient eligibility retrieval.

4. Output Delivery:
   - AI outputs formatted CDT codes table, shared frequencies, and deductible math.
   - Automatically saves to persistent PostgreSQL history under active clinic workspace.
   - Automatically generates instant Excel breakdown and PMS note.
