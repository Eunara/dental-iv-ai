--------------------------------------------------------------------------------
PRIORITY 1: FULL-PAGE GATEKEEPER LOGIN (STRICT CLINIC ACCESS CONTROL)
--------------------------------------------------------------------------------
* Objective: When anyone opens `dentverify.com`, they must NOT freely access the site.
  Instead, a full-screen modern Gatekeeper Login Screen appears immediately.

1. Full-Screen Gatekeeper Landing Screen:
   - Blurs/hides the entire dashboard, uploader, history, and settings until authenticated.
   - Professional Dental RCM branded login box with:
     * Email / Username field
     * Password field
     * "Sign In to Clinic Workspace" button
     * Error / validation feedback banner
   - Auto-checks `/api/auth/me` on initial page load:
     * If valid active cookie exists -> instantly unlocks dashboard.
     * If unauthenticated or expired -> displays Gatekeeper Login Screen.

2. Backend Route & API Lockdown:
   - Guard `/api/verify`, `/api/prompts/*`, `/api/verifications` behind strict `authMiddleware`.
   - Returns 401 Unauthorized if request does not contain a valid JWT session cookie.
   - Logout button in top navigation immediately clears the cookie and resets the UI
     back to the Gatekeeper Login Screen.

--------------------------------------------------------------------------------
PRIORITY 2: DEDICATED INSURANCE DIRECTORY & SUB-PORTAL MANAGER
--------------------------------------------------------------------------------
* Objective: Separate Insurance Directory from AI Settings into its own dedicated
  manager. Support complex multi-portal carriers like Delta Dental (DD CA, DD FEP).

1. Hierarchical Multi-Portal Payer Structure:
   - Delta Dental (Parent Carrier)
     * DD CA  - Delta Dental of California (Claims Address, Payor ID, Phone, In/Out Network)
     * DD FEP - Delta Dental Federal Employees Program (Claims Address, Payor ID, Phone, In/Out Network)
     * DD PPO / Premier / Regional
   - MetLife Dental
   - Cigna Dental
   - Guardian Dental
   - Aetna / Humana / Ameritas

2. Dedicated Management UI ("Insurance Directory & Portals"):
   - Independent button in top navigation bar (`Insurance Portals & Addresses`).
   - Clean card/list view displaying each carrier and its sub-portals.
   - Fields per sub-portal:
     * Portal Sub-Name (e.g. DD CA, DD FEP)
     * Claims Mailing Address
     * Electronic Payor ID
     * Provider Phone Number
     * Contracted Network Status toggle (In-Network / Out-of-Network)
   - Add, Edit, Delete sub-portals with persistent storage in PostgreSQL `dentverify.payer_credentials`.

3. Frontend Auto-Wiring:
   - When a breakdown or patient document identifies e.g. "DD CA" or "Delta Dental FEP",
     the system automatically wires the exact matching sub-portal's Claims Address,
     Phone, and Payor ID into Cell 8 of the "policy-details-compact-grid" and Hero Banner.

--------------------------------------------------------------------------------
PRIORITY 3: BACKGROUND HEADLESS BROWSER VERIFICATION (PLAYWRIGHT AUTOMATION)
--------------------------------------------------------------------------------
* Objective: Staff enters Member ID + DOB + Payer -> System opens a background
  headless browser, logs into the provider portal, retrieves live benefits,
  and renders the full breakdown table automatically.

1. Unified Auto-Verify Input Panel in Frontend:
   - Toggle switch on main screen:
     [⚡ Run Background Auto-Verify]  vs  [📄 Manual Document Upload]
   - Input Fields:
     * Insurance Portal Dropdown: [DD CA | DD FEP | Cigna | MetLife | Guardian]
     * Subscriber / Member ID: [____________________]
     * Patient DOB: [MM/DD/YYYY]
     * Patient Name: [Last, First]
   - Button: [⚡ Run Auto-Verify & Generate Breakdown]
   - Live Progress Status Indicator:
     "Launching background runner..." -> "Authenticating into portal..." ->
     "Fetching patient benefits..." -> "AI Clinical Audit in progress..." -> "Done!"

2. Backend Playwright Automation Runner:
   - Headless browser runner hosted on VPS (`automation/payers/`).
   - Loads encrypted clinic credentials for selected portal from PostgreSQL vault.
   - Navigates to portal login URL and authenticates.
   - Enters Patient Subscriber ID and DOB into portal search form.
   - Captures benefits summary (PDF download or HTML DOM snapshot).
   - Hands document buffer directly into Gemini AI RCM audit pipeline.

3. Human-in-the-Loop 2FA / OTP Relay Modal:
   - If portal prompts 2FA SMS or email code on login:
     * Runner pauses and triggers live OTP prompt in DentVerify frontend:
       "2FA Code Required: Enter code sent to clinic [phone/email]: [ _____ ] [Verify]"
     * Staff enters code -> runner resumes session and completes patient eligibility retrieval.

4. Output Delivery:
   - AI outputs formatted CDT codes table, shared frequencies, and deductible math.
   - Automatically saves to persistent PostgreSQL history under practice.
   - Automatically generates instant Excel breakdown and PMS note.
