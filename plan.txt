1. HIPAA TECHNICAL SAFEGUARDS COMPLIANCE (45 CFR Part 164)
--------------------------------------------------------------------------------
* § 164.312(a)(1) Access Control:
  - Unique user identification and credential management.
  - Role-Based Access Control (RBAC): Admin vs Clinic Staff.
  - Multi-tenancy: Clinic A cannot view data from Clinic B.
  - Strong password policy enforced (min 10 chars, uppercase, lowercase, numbers, symbols).
  - Bcrypt password hashing (salt rounds: 12).

* § 164.312(a)(2)(iii) Automatic Logoff:
  - Enforce session timeout after 15 minutes of inactivity.
  - Visual warning countdown before auto-logout occurs.

* § 164.312(a)(2)(iv) Data Encryption at Rest:
  - Field-level encryption using AES-256-GCM for all patient identifiers (Patient Name, DOB, Subscriber ID).
  - AES-256-GCM encryption for stored payer portal credentials (usernames, passwords, PINs).
  - Encryption keys stored securely in environment variables, never committed to git.

* § 164.312(b) Audit Controls & Audit Trail:
  - Tamper-evident logging of all ePHI access events:
    [TIMESTAMP] [USER_ID] [OFFICE_ID] [ACTION] [RECORD_ID] [IP_ADDRESS] [USER_AGENT]
  - Actions logged: LOGIN, LOGOUT, AUTO_VERIFY_TRIGGER, ANALYZE_FILE, VIEW_HISTORY_ITEM, EXPORT_EXCEL, DELETE_RECORD.
  - Audit logs are append-only; standard users cannot modify or delete audit trails.

* § 164.312(e)(1) Transmission Security:
  - Full TLS 1.3 / HTTPS enforced via Cloudflare and Nginx.
  - HSTS enabled.

2. DATABASE ARCHITECTURE (POSTGRESQL)
================================================================================

A. practices (Organizations / Clinics)
   - id: UUID (Primary Key)
   - name: VARCHAR(255)
   - subscription_tier: VARCHAR(50) DEFAULT 'pro'
   - created_at: TIMESTAMP WITH TIME ZONE DEFAULT NOW()

B. users (Clinic Accounts)
   - id: UUID (Primary Key)
   - practice_id: UUID (Foreign Key -> practices.id)
   - email: VARCHAR(255) UNIQUE NOT NULL
   - password_hash: VARCHAR(255) NOT NULL
   - full_name: VARCHAR(255) NOT NULL
   - role: VARCHAR(50) DEFAULT 'staff'  -- 'admin' or 'staff'
   - is_active: BOOLEAN DEFAULT TRUE
   - last_login_at: TIMESTAMP WITH TIME ZONE
   - created_at: TIMESTAMP WITH TIME ZONE DEFAULT NOW()

C. payer_credentials (Encrypted Portal Vault)
   - id: UUID (Primary Key)
   - practice_id: UUID (Foreign Key -> practices.id)
   - payer_key: VARCHAR(50) NOT NULL         -- 'delta_dental', 'metlife', 'cigna', 'guardian'
   - username_enc: TEXT NOT NULL             -- AES-256-GCM encrypted
   - password_enc: TEXT NOT NULL             -- AES-256-GCM encrypted
   - tax_id_or_npi: VARCHAR(50)              -- Office NPI/TIN if required by portal
   - extra_data_enc: TEXT                    -- Security questions / PINs encrypted
   - status: VARCHAR(50) DEFAULT 'active'    -- 'active', 'invalid_credentials', 'otp_required'
   - last_used_at: TIMESTAMP WITH TIME ZONE
   - updated_at: TIMESTAMP WITH TIME ZONE DEFAULT NOW()

D. verifications (Persistent Insurance History)
   - id: UUID (Primary Key)
   - practice_id: UUID (Foreign Key -> practices.id)
   - user_id: UUID (Foreign Key -> users.id)
   - source: VARCHAR(50) DEFAULT 'manual_upload' -- 'auto_portal', 'manual_upload'
   - insurance_payer: VARCHAR(255)
   - patient_name_enc: TEXT NOT NULL         -- AES-256-GCM encrypted
   - member_id_enc: TEXT                     -- AES-256-GCM encrypted
   - dob_enc: TEXT                           -- AES-256-GCM encrypted
   - network_status: VARCHAR(100)
   - full_breakdown_json: JSONB NOT NULL     -- Complete structured breakdown data
   - created_at: TIMESTAMP WITH TIME ZONE DEFAULT NOW()

E. audit_logs (Immutable HIPAA Access Logs)
   - id: UUID (Primary Key)
   - user_id: UUID (Foreign Key -> users.id)
   - action: VARCHAR(100) NOT NULL           -- 'LOGIN', 'AUTO_VERIFY', 'VIEW_RECORD', etc.
   - target_id: UUID                         -- verification ID accessed
   - ip_address: VARCHAR(45)
   - user_agent: TEXT
   - metadata: JSONB
   - created_at: TIMESTAMP WITH TIME ZONE DEFAULT NOW()

PHASE 6: CLINICAL RCM BUSINESS LOGIC ENGINE & FREQUENCY NOTATION
================================================================================
1. COMPACT FREQUENCY STANDARDIZATION ENGINE:
   - Automated conversion of long portal sentence strings into standard clinical notation:
     * "two of any ... within a calendar year" -> "2x1yr"
     * "two of any ... within a 12 months" -> "2x12m"
     * "one of any ... within a calendar year" -> "1x1yr"
     * "one of any ... within a 12 months" -> "1x12m"
     * "1 in 60 months / once every 5 years" -> "1x5yr"
     * "1 in 36 months / once every 3 years" -> "1x3yr"
     * "1 in 24 months / once every 2 years" -> "1x24m"
     * "no frequency limit / unlimited" -> "NF"
     * "once per lifetime" -> "1/LT"
     * "1 per tooth lifetime" -> "1/tooth LT"
   - Implemented at both Gemini AI prompt directive level and backend/frontend post-processor functions.

2. CALENDAR YEAR VS ROLLING 12-MONTH RESET LOGIC:
   - Calendar Year Plans: Procedure counters reset every January 1st.
     * If a procedure has a prior calendar year history date (e.g. 10/25/2025 vs current 2026),
       patient is automatically flagged as ELIGIBLE (is_eligible: true).
   - Rolling 12-Month Plans (e.g. 2x12m): Evaluates the exact 12-month rolling window from last service date.
     * If 1 of 2 procedures was consumed within the last 12 months, patient remains eligible for 1 remaining procedure.

3. D0210 (FMX) & D0330 (PANO) MUTUAL SHARED FREQUENCY ENGINE:
   - FMX and Panoramic Radiographs always share frequency limitations (typically 1 in 60 months / 5 years).
   - Cross-code history syncing: A service date on either code is mutually applied to both.
   - Computes precise next eligible date based on frequency elapsed months.

4. D1206 / D1351 / ADULT AGE LIMIT LOGIC:
   - Minimum Age Boundaries: Adult procedures (e.g. D1110, D4346 min age 14) are verified so that
     adults (e.g. 27 years old) are flagged ELIGIBLE rather than misclassified as exceeding age limits.
   - Maximum Age Boundaries: Pediatric/youth procedures (D1206 Fluoride, D1351 Sealants, Ortho) flag
     ineligibility when the patient strictly exceeds the ceiling age (e.g. age 27 > 14).
